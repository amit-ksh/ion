# Using this submission pack

`DEVPOST.md` contains the project story, a short pitch, future plans, proposed pricing direction, the built-with list, and a captioned screenshot gallery. Upload the six PNGs from `screenshots/` as gallery images. Relative Markdown image links work in this local pack; use the uploaded image URLs if adding them to a hosted description.

Pricing is deliberately described as proposed. The current free/BYOK offering is distinguished from optional future managed services and team plans. Account switching is described as an expansion of existing connection/account foundations.

The fifth image is the approved, authored Aurora showcase inside the existing demo's recorded app window. Its caption identifies it as showcase content. The other images come from existing Ion captures. Source paths are recorded in `screenshots-sources.json`; no new app visual test was run for this pack.
